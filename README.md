# Прогнозирование сроков доставки заказов Olist

Учебный проект по классическому машинному обучению. Задача — предсказать фактическое время доставки в днях на момент оформления заказа. Данные относятся к электронной коммерции в Бразилии, не к железнодорожным перевозкам.

## Данные

Источник: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (Olist, лицензия датасета **CC BY-NC-SA 4.0**).

Использованы три таблицы: `olist_orders_dataset.csv`, `olist_customers_dataset.csv`, `olist_order_items_dataset.csv`. Исходные CSV в репозитории **не публикуются**. Их необходимо скачать со страницы Olist на Kaggle.

## Что сделано

- Анализ дубликатов, пропусков и распределений.
- Объединение таблиц по `customer_id` и `order_id`.
- Признаки: обещанный срок доставки, цена товаров, стоимость доставки и штат покупателя.
- Разделение по времени: первые 80% заказов — train, последние 20% — test.
- `SimpleImputer`, `StandardScaler`, `OneHotEncoder`, `ColumnTransformer`.
- Сравнение медианного прогноза, Ridge, Decision Tree, Random Forest, Gradient Boosting и CatBoost с `TimeSeriesSplit` на тренировочной части.
- Выбор лучшей модели по CV MAE и однократная проверка на test.

Предобработка обучается только на тренировочной части каждого разбиения, чтобы избежать утечки статистик из валидации и теста.

## Результаты

**MAE (дни), меньше — лучше.**

| Модель | Временная CV (train) |
|---|---:|
| CatBoost | 5.626 |
| Random Forest | 5.627 |
| Gradient Boosting | 5.634 |
| Ridge | 5.663 |
| Decision Tree | 5.725 |
| Медиана | 6.841 |

Итоговая проверка на test:

| Прогноз | Test MAE |
|---|---:|
| Медиана | 4.963 дня |
| CatBoost | 3.982 дня |

MAE относительно медианного прогноза снизилась примерно на 19.8%, но качество всё ещё ограничено простым набором признаков. Близкие результаты CatBoost и Random Forest на CV не позволяют считать первый алгоритм однозначно лучше при любых данных.

## Запуск

1. Скачайте датасет по ссылке выше и создайте папку `data/` рядом с ноутбуком.
2. Положите в `data/` три CSV, перечисленные в разделе «Данные».
3. Установите библиотеки:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Откройте `delivery_prediction.ipynb` в Jupyter и выполните **Restart & Run All**.

При выполнении ноутбука автоматически создаётся папка `results/` и сохраняются две таблицы `.csv` и четыре графика `.png`. Если удалить папку `results/`, при следующем запуске она создастся заново.

Если CSV уже расположены в `~/ML_private_datasets/olist/`, ноутбук использует их автоматически, когда нет файлов в локальной папке `data/`.

## Ограничения

Проект оценивает время доставки на исторических *завершённых* заказах. Фактическая дата доставки используется только для целевой переменной, но не как признак. Использование результатов для реальных заказов требует дополнительной проверки доступности всех признаков в момент прогноза и качества на новых данных.
