# Delivery Time Prediction — Olist

Прогнозирование фактического времени доставки заказов Olist. **Это данные электронной коммерции, а не железнодорожных перевозок.**

## Методы

- Объединение таблиц заказов, покупателей, товаров и продавцов по идентификаторам.
- Признаки, известные на момент оформления заказа; исключение фактической даты доставки из признаков.
- Хронологическое разделение: train (64%), validation (16%), test (20%).
- Ridge, Decision Tree, Random Forest, HistGradientBoosting; выбор по validation MAE.
- Сравнение с медианным базовым прогнозом на отложенной тестовой выборке.

## Результаты

| Метод | Test MAE, дней |
|---|---:|
| Медианный прогноз | 4.963 |
| Ridge (лучшая ML-модель по validation) | 6.450 |

ML-модель **не превзошла** базовый прогноз. Результаты относятся к указанному разбиению; качество можно исследовать дальше, например, добавляя признаки и более строгую модель данных. Полные результаты и графики — в `results/`.

## Запуск

```bash
pip install -r requirements.txt
python download_data.py
```

Открыть `delivery_prediction.ipynb` в JupyterLab и запустить ячейки. Скрипт скачивает исходные CSV **вне репозитория**: `~/ML_private_datasets/olist/`. Ноутбук читает данные оттуда же.

Источник: [Olist Brazilian E-Commerce](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), лицензия датасета CC BY-NC-SA 4.0. Исходные CSV не распространяются в репозитории.
